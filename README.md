# WholeBody73 Local Inference Lab
指定された `c513f6e24e0ef0d10a98545086d4a90968474074` から分岐した推論専用サイト。学習サイトとは別のSitesプロジェクトで動作する。

## 使い方
1. 学習チェックポイントのJSONまたはgzip圧縮JSONを選択する。ファイル名の制約はない。内容のformat/schemaと全重みの名前・形状・有限値を検証する。
2. ブラウザでONNXを生成し、ONNX Runtime Webの推論セッションを作成する。「生成したONNXを保存」で取得できる。
3. 動画を選択する。VRMは任意。「現在フレームを推論」または「推論開始」を選ぶ。
4. 人物ごとの2D関節、3D骨格、VRMを確認する。「入力プレビュー」で各人物について実際にモデルへ渡した画像と、その画像から出力された骨格を確認できる。「骨格を重ねる」で画像だけの表示に切り替えられる。

## 入出力と制約
- ファイルはすべて端末内で読み込む。動画・VRM・チェックポイント・生成ONNXをサーバーへ送信しない。チェックポイントはリポジトリに含めない。
- 初回にCDNからThree.js、three-vrm、TensorFlow.js、COCO-SSD、ONNX Runtime Webと人物検出用の重みを取得する。VRMの外部URIリソース参照は拒否する。
- 学習側のmodel.mjs / onnx.mjs / video-model.mjs / schema.mjsを使用する。ランダム重みで補完せず、完全なチェックポイントだけを変換する。動画モデルでは人物IDごとの3フレーム履歴を使う。
- COCO-SSDで人物を検出し、各検出枠を縦横比0.75へ拡張して1.25倍の余白を設け、192×256の人物画像で順次推論する。RGBを0〜1に正規化したNCHWを入力する。2D出力を実際の入力矩形から元映像へ戻す。画像外の部分は黒で埋める。
- 73関節×1組を返す同じモデルを人物ごとに実行して複数人を扱う。人物の対応付けは検出枠の重なりと近傍候補を使う簡易方式で、交差や長い遮蔽ではIDが変わる場合がある。
- 表示は推論完了時に一括更新し、待機中は前回の骨格を保持する。3D座標バッファを再利用する。シーク時は履歴を破棄し、古い非同期推論結果を表示しない。
- 動画を停止したときや停止中にシークしたときは、その時刻の映像を再推論する。再生中は推論時間に応じて映像に対する骨格の遅れが生じる。
- 出力座標は学習モデルのUnity軸（+X右、+Y上、+Z前方、腰中心、m）。表示時にZを反転してThree.jsの右手座標へ変換する。
- 関節の奥行きはモデル出力。人物全体の配置距離は画角、指定身長、検出枠の高さから求める概算で、実測距離ではない。
- confidenceは学習側定義のヒートマップ集中度であり、校正された可視性確率ではない。初期表示しきい値0は不確かな出力も確認するため。
- GPU非対応・セッション作成失敗時はWASMへフォールバックする。速度は端末・動画による。
- 埋め込みVRM 0.x/1.0の主要ボーンのみを駆動し、指・表情のリターゲットは実装対象外。
- GitHub Actionsの検証ワークフローと追加テストは削除した。動画による実験はローカルで行う。
